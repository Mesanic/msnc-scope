# FORMATS.md — store records, CLI output shapes, exit codes

All shapes verified against `lib/store.mjs`, `lib/resolve.mjs`, `lib/ledger.mjs`,
`lib/check.mjs` and the CLI handlers. JSONL files are UTF-8, LF-terminated, one record per
line, fixed key order (never re-serialize after hand-editing).

## Store layout

```
<root>/.scope/symbols/
  index/                  # gitignored via `scope init`
    meta.json             # schema gate + per-file hashes + stats (only place timestamps live)
    nodes-000.jsonl       # symbol records, sorted by id
    edges-000.jsonl       # edge records, sorted by src|dst|type|label|confidence
    facts-000.jsonl       # per-file raw extraction cache (internal; enables fast rescan)
    check-latest.json     # machine summary of the last `scope check` (volatile derived state)
  ledger/
    notes.jsonl           # committed to git — human notes keyed by source hash
  view-data.html          # generated by `scope view`; gitignored via `scope init`
```

## Node record (`nodes-000.jsonl`)

```json
{"_":"node","id":"fn:89aa5d44a113","kind":"function","lang":"typescript","path":"src/user.ts","name":"createUser","span":{"sl":7,"sb":196,"el":9,"eb":330},"sigHash":"1c3f6d2ea8e04a27","confidence":"exact","sig":"createUser(name: string, email: string): User","exported":true,"decorators":[],"summary":"Build a User record from raw signup fields."}
```

- `id`: `<kindPrefix>:<sha256(path|name|span|sigHash)[:12]>` — content-derived, stable
  across runs/platforms. Prefixes: `fn method cls iface type enum mod route sym`.
- `kind`: function · method · class · interface · type · enum · module · route ·
  symbol (rough fallback only).
- `span`: `sl/el` = start/end line (1-based), `sb/eb` = byte offsets.
- `confidence`: exact | heuristic | rough. `rough` only from unknown-extension fallback.
- `decorators`: array of captured decorator/attribute texts (may be empty).
- `summary`: first doc-comment paragraph or docstring, else null.

## Edge record (`edges-000.jsonl`)

```json
{"_":"edge","src":"fn:a5bb9c344fdf","dst":"fn:89aa5d44a113","type":"call","label":null,"confidence":"exact","f":"src/service.ts"}
```

- `type`: call · import · contains · route · extends · implements · tests.
  (`label` exists in the schema but is always null today.)
- `confidence`: exact = grammar + resolved binding without barrel overflow; heuristic =
  same-file fallback, this-dispatch, convention test pairing, Go iface satisfaction,
  deep-barrel fallback; rough never appears on edges.
- `f`: origin file of the edge (attribution for stats).

## meta.json

```json
{"_":"meta","schemaVersion":1,"tool":"scope-symbols@0.0.1","createdAt":"…","updatedAt":"…",
 "complete":true,"durationMs":42,
 "stats":{"files":9,"scanned":2,"reused":7,"skippedBinary":0,"skippedOversize":0,"failed":0,
          "unresolvedImports":11,"droppedCalls":16,"barrelOverflows":0,
          "languages":{"typescript":9},"bytes":3404,
          "nodes":{"total":22,"byKind":{"function":12,"interface":1,"module":9}},
          "edges":{"total":37,"byType":{"call":14,"contains":13,"import":8,"tests":2}}},
 "files":{"src/user.ts":{"hash":"…","size":330,"mtimeMs":1730000000000,"lang":"typescript"}}}
```

`schemaVersion > tool's version` ⇒ every command refuses (exit 2). An OLDER schema is
rebuilt transparently by the answering commands (locate/impact/slice/brief/note/check)
via a forced full scan; the read-only `stats` and `view` refuse it instead (exit 2,
"run `scope scan` to rebuild"). `complete:false` ⇒ queries refuse (exit 2).

## Note records (`ledger/notes.jsonl`, committed)

Symbol note:

```json
{"_":"note","v":1,"op":"set","kind":"symbol","key":"0f1fe224e7e43ff3","nodeId":"fn:a5bb9c344fdf","path":"src/service.ts","span":{"sl":13,"el":20},"name":"registerUser","text":"Throws when name is blank."}
```

Edge note: same header, `"kind":"edge"`, `"key":"<fromKey>-><toKey>"` plus
`fromKey,toKey,fromNodeId,toNodeId,fromPath,toPath,fromSpan,toSpan`.

- **Key** = `sha256(sigHash|normalizedBody)[:16]` where normalizedBody strips BOM/CRLF,
  trims trailing whitespace, drops blank edges and dedents. Display form: `src:<key>`
  (edge display: `src:<k1>->src:<k2>`).
- Records are append-only; **last record per key wins** when reading. Moves rebind
  automatically at next `scope check`; identical bodies collide as ambiguous; no candidate
  ⇒ orphan.

## check-latest.json

Fixed-key-order projection of the last check report:
`{v:1, schemaVersion, tool, root, issues, counts:{drift,dangling,orphans,ambiguous,rebindings}, dirty:{edited[],deleted[],added}, drift[], dangling[], orphans[], ambiguous[], rebindings[], runners[], runnerSources{}, tests[]}`.
Volatile derived state inside gitignored `.scope/symbols/index/`; regenerated on every check;
corrupt/absent file simply disables the Change Lens.

## CLI stdout formats

- `locate <q>` — one line per hit:
  `<id> <kind> <name> <path>:<sl>-<el> <confidence> <sig>` — sig ellipsized so the whole
  line stays ≤ ~40 tokens. No hits: `no results for "<q>"`. `--json` emits one compact
  object `{query, hits:[{id,kind,name,path,span:{sl,el},confidence,sig,score}]}` (never
  truncated).
- `impact <key>` —
  ```
  impact <id> <name> [dir]
  def: <path>:<sl>-<el> (<kind>, <confidence>)
  direct (N)
    <conf> <id> <name> <path>:<sl>-<el>
  tests (N)
    <conf> <test-path>
  transitive (N, by module)
    <module-id> (M):
      <conf> <name> <path>:<sl>
  +K more (narrow with --depth N or filter)      ← only when truncated
  no dependents found                            ← only when empty
  ```
  Hard cap ≤ 600 tokens enforced in code. Default direction is **down**; pass `--up`
  for callers.
- `slice <key|path:a-b>` — 3-line header, separator, verbatim lines:
  ```
  file: <posix-path>
  span: <sl>-<el>
  symbol: <name> (<kind>, <confidence>) | - for ranges
  ---
  …source…
  ```
  Over budget ⇒ refusal, nothing emitted: `slice of <p>:<a>-<b> is ~T tokens, over the
  B-token budget; narrow the line range or raise --max-tokens` (exit 2).
- `brief <key>` — card ≤ 150 tokens: `brief <name> <id>` / `def:` / `refs: up=N down=N
  (exact=X, heuristic=Y)` / optional `tests:` / optional `sig:` / up to 3 clipped preview
  lines.
- `check` — clean: `check: clean` (or `check: clean (N rebound)`).
  Issues: `check: K issues (drift D, dangling G, orphans O, ambiguous A)` followed by
  greedy-filled sections `drift / dangling / orphans / ambiguous / rebindings /
  tests (runners: …)` and an explicit `+N more (use --json for the full report)` hint;
  human report capped at 200 tokens. The report is a diff against the pre-run snapshot:
  each check re-baselines, so a repeat run acknowledges what it saw (exit 0) even when
  nothing was fixed. `--json`: full fidelity, single line, never
  truncated.
- `note set|edge` — echoes binding: `note set src:<key> -> <nodeId> (<path>:<sl>-<el>)`;
  `note edge src:<k1>->src:<k2> (<fromId> -> <toId>)`.
- `init` — `init <mapDir>` / index+ledger status lines / gitignore status;
  warns if `.gitignore` ignores `.scope/symbols/` wholesale.
- `stats` — fixed small format; multi-value lists sorted; volatile block explicitly
  flagged `lastScan (volatile):`.
- `scan` — stderr progress: `scan: T files tracked · S scanned · R reused · N nodes · E
  edges` (plus `· N binary skipped` / `· N oversize skipped (cap 1048576 B)` segments
  when non-zero), `store: <posix-dir>` (+ `(incomplete: see warnings)`), then one
  `warning:` line per failed extraction and one `note:` line per oversize-skipped source.
  Stdout is intentionally empty (pipe-safe).
- `view` — `view <out-posix> (S of T symbols, SE of TE relations, B bytes)`; truncation
  adds a stderr warning about the banner.

## Exit-code contract

| Code | Meaning | Raised by |
|---|---|---|
| 0 | success (queries answer even when "no results") | all commands |
| 1 | verification failed OR operational write failure | `check` while THIS run detects new drift/dangling/orphans/ambiguous vs its pre-run snapshot; `LedgerLockError`; `LedgerCorruptError`; unexpected internal errors |
| 2 | usage error / unanswerable environment | unknown subcommand or flags; missing args; `IndexVersionError` (newer schema); `IncompleteIndexError`; `StoreCorruptError`; `SliceTooLargeError`; `ViewOutputError`; bad `--root` |

Rule of thumb for agents: exit 2 means fix your invocation or rescan (`scope scan`);
exit 1 from `check` means THIS run detected changes needing attention — findings are
acknowledged by the next run, since every check re-baselines rather than accumulating a
defect list; anything else from `check` should be
treated as "verification did not run".
